# Basics

This section covers the fundamental building blocks of C++. Every topic in this folder is designed to introduce one concept at a time through simple, executable examples.

## Topics

* Variables
* Data Types
* Input & Output
* Operators
* Type Casting
* Constants

## Learning Outcomes

After completing this section, you should be able to:

* Declare and initialize variables
* Choose appropriate data types
* Read input and display output
* Use common operators
* Convert between data types
* Work with constant values

## Files

| File               | Description                                     |
| ------------------ | ----------------------------------------------- |
| `variables.cpp`    | Declaring, initializing, and updating variables |
| `data_types.cpp`   | Built-in C++ data types                         |
| `input_output.cpp` | Using `cin` and `cout`                          |
| `operators.cpp`    | Common C++ operators                            |
| `type_casting.cpp` | Implicit and explicit type conversion           |
| `constants.cpp`    | Using `const` to create constant values         |
